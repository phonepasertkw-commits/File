🔗 Google Sheets Sync
📋 ວິທີຕັ້ງຄ່າ Google Apps Script (ຄັ້ງດຽວ)
  1. ເປີດ sheets.google.com ແລ້ວສ້າງ Spreadsheet ໃໝ່
  2. ໄປທີ່ເມນູ Extensions → Apps Script
  3. ລຶບໂຄ້ດເກົ່າໃນໜ້າຈໍທັງໝົດ, ວາງໂຄ້ດຂ້າງລຸ່ມນີ້ແທນ
  4. ກົດ Deploy → New deployment → ເລືອກ type "Web app"
  5. Execute as: Me, Who has access: Anyone
  6. ກົດ Deploy, copy URL ທີ່ໄດ້ ມາໃສ່ຊ່ອງຂ້າງເທິງ ແລ້ວກົດ "ບັນທຶກ URL"
